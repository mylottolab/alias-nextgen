전화가 안 울리는 경우, 거의 이 셋 중 하나입니다.

1. 알림 허용

이게 꺼져 있으면 벨이 아예 안 울립니다.

설정 → 애플리케이션 → Alias → 알림 → 켜기

2. 배터리 제한 풀기

폰이 배터리를 아끼려고 앱을 재우면, 벨이 울리다 중간에 멈추거나 아예 안 울립니다.

설정 → 애플리케이션 → Alias → 배터리 → 제한 없음 고르기

삼성 폰은 설정 → 배터리 → 백그라운드 사용 제한 에도 Alias 가 들어 있지 않은지 봐주세요.

3. 소리 크기

통화 소리는 일반 전화의 음량이 아니라 "미디어" 음량으로 나옵니다. 그게 낮으면 통화가 잘 연결돼도 상대 목소리가 작게 들립니다.

통화 중에 음량 버튼 위쪽을 몇 번 눌러보세요

무음 모드나 방해금지가 켜져 있으면 벨이 안 납니다. 함께 확인해 주세요.
